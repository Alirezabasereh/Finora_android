# Finora (Android)

## بیلد
محتوای این پوشه را در ریشه‌ی ریپو بگذار و push کن؛ GitHub Actions خودکار APK می‌سازد (Artifacts → `Finora-debug-apk`).

## وضعیت
- مرحله ۱: اسپلش، ورود/ثبت‌نام/بازیابی رمز، همگام‌سازی با Supabase، تم، نوار پایین.
- مرحله ۲ (الف): صفحه‌ی خانه — هدر، کارت اصلی (موجودی، حلقه‌ی بودجه، حساب‌ها، درآمد/هزینه، تراز امروز، سلامت مالی)،
  تقسیم هزینه‌ها (نمودار + درصد + سوییچ اقساط)، چیپ‌های بینش و لیست تراکنش‌ها؛ همراه با
  چرخه‌ی ماه (آرشیو خودکار ماه قبل و انتقال موجودی) دقیقاً مثل نسخه‌ی وب.
- مرحله ۲ (ب) بعدی: ثبت/ویرایش/حذف تراکنش و مودال فیلتر.

## تنظیم لینک بازیابی رمز (یک بار، در Supabase)
Authentication → URL Configuration → Redirect URLs → `finora://auth-callback`
