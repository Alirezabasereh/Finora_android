# Finora (Android) — مرحله ۱

اپ نیتیو اندروید (Kotlin + Jetpack Compose) نسخه‌ی وب Finora.

## بیلد
1. محتوای این پوشه را در ریشه‌ی ریپو قرار بده و push کن.
2. GitHub Actions (`.github/workflows/build-apk.yml`) خودکار اجرا می‌شود.
3. فایل APK را از Artifacts با نام `Finora-debug-apk` دانلود کن.

## تنظیم لینک بازیابی رمز (یک بار، در Supabase)
Authentication → URL Configuration → Redirect URLs → اضافه کن: `finora://auth-callback`
(بدون این، ایمیل بازیابی همان لینک نسخه‌ی وب را باز می‌کند که آن هم کار می‌کند.)

## مرحله ۱ شامل
- اسپلش، ورود، ثبت‌نام، فراموشی رمز، تعیین رمز جدید (با دیپ‌لینک)
- همگام‌سازی دوطرفه با همان جدول `user_data` (داده‌ها بین وب و اپ مشترک است)
- تم تیره/روشن/سیستم، فونت Vazirmatn و آیکون‌های Font Awesome داخل اپ
- نوار پایین و نوار همگام‌سازی
- صفحه‌ی خانه فعلاً موقتی است (حساب، آمار همگام‌سازی، تم، خروج)
